# Security Policy

## Supported Versions

action-dryrun is pre-1.0. Security fixes target the latest `main` branch and the newest published package version.

## Reporting a Vulnerability

Please report vulnerabilities privately to the repository owner instead of opening a public issue with exploit details.

Include:

- affected version or commit
- steps to reproduce
- expected impact
- any safe proof-of-concept artifacts

Do not include secrets, private tokens, proprietary workflow data, or sensitive logs in reports or fixtures.
